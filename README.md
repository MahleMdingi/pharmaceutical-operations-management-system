# Pharmaceutical Operations Management System

## Overview
This project is a SQL Server database design project that simulates a real-world pharmaceutical operations management system.

The goal of the system is to support:
- Product management
- Batch tracking
- Inventory management
- Supplier management
- Order processing
- Shipment tracking

## Business Problem
Pharmaceutical companies require accurate tracking of medication inventory, manufacturing batches, suppliers, warehouses, and customer orders.

This project aims to design a relational database capable of supporting those operational workflows efficiently.

## Current Features
- Product & category management
- Batch tracking
- Inventory management
- Warehouse tracking
- Supplier relationships
- Customer orders
- Shipment tracking
